# Discord Timetable Bot

Discord bot that posts the class timetable every day and answers `!emploi` with the schedule of any day.

## Features

- Daily automatic post of the day's courses
- `!emploi [offset]` command: today, tomorrow (`!emploi 1`) or any other day
- Clean message formatting for each course

## Tech Stack

- Python 3, discord.py
- requests

## Getting Started

```bash
git clone https://github.com/ghostland-dev/discord-bot.git
cd discord-bot
pip install discord.py requests
export DISCORD_TOKEN=your-bot-token
python discord.py
```
